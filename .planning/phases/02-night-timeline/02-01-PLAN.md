  <name>Task 1: Add a `useNightTimeline` hook with tests</name>
  <files>
  src/components/design/useNightTimeline.ts,
  src/components/design/useNightTimeline.test.ts
  </files>
  <action>
  TDD: write the test file first, expecting `useNightTimeline` to not exist.

  API:
  ```ts
  function useNightTimeline(childId: string, now: Date): {
    at: Date,
    med: string,    // short med name, e.g. "Nurofen"
    medId: string,
  }[]
  ```

  Semantics:
  - Anchor the window to today's 21:00 (or yesterday's 21:00 if `now <
    21:00`), same as `anchorStrip()` in `HomeB.tsx`. Extract that logic into
    the hook OR call it from there — your call, but tests must cover it.
  - End of window is anchor + 12h.
  - Filter `doseStore.listFor(childId, { since, until })`.
  - Map each record to `{ at: new Date(administeredAt), med: shortName,
    medId }`. `shortName` resolves via `DEFAULT_MEDICATIONS` lookup;
    fallback to `medId` if not found (defensive).
  - Sort by `at` ascending.
  - Returns a stable reference when the underlying records haven't changed
    (use `useSyncExternalStore` or a `useMemo` keyed on a stable signature).
    Tests should NOT rely on referential stability — that's an
    implementation detail — but should assert the array contents.

  Test cases:
  - Empty store → empty array.
  - One record administered 30 min before `now` → array of length 1 with
    correct shape.
  - Records for other children → excluded.
  - Records outside the 12h window → excluded.
  - Med name resolution: Nurofen short name comes out as `"Nurofen"`
    (not the full `"Nurofen/Algin (Ibuprofen 100mg/5ml)"`).
  - When `now` is 03:00 and a record is at 21:30 the previous day, it IS
    included (window starts at 21:00 prior).

  Use Vitest fake timers (`vi.useFakeTimers`, `vi.setSystemTime`) to control
  `now` in tests.

  Avoid: re-implementing anchor logic in two places. Either import it from
  `HomeB.tsx` (after exporting it) or move it into `useNightTimeline.ts`
  and import it back in `HomeB.tsx`. Latter is cleaner.
  </action>
  <verify>
  - All `useNightTimeline` tests pass.
  - `npm run type-check` passes.
  </verify>
  <done>
  Hook with full test coverage on the listed cases.
  </done>
