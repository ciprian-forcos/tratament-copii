<objective>
Build a typed, versioned, URL-safe encode/decode library for share state.
Pure functions, no UI, no React. The library takes a typed payload (one or
more children, optionally custom medications) and returns a `?import=...`
URL, and vice versa.

Purpose: Tier 1 sharing is essentially a serialization problem. Get the
serializer right first, in isolation, with tests.
Output: `src/components/design/share/encoder.ts` + tests.
</objective>

<task type="auto">
  <name>Task 1: Write failing encoder/decoder tests</name>
  <files>src/components/design/share/encoder.test.ts</files>
  <action>
  API to test:
  ```ts
  // Payload shape — versioned, narrow, explicit.
  interface SharePayload {
    v: 1
    children: Child[]            // full Child objects, sans transient `temp`
    medications?: Medication[]   // omitted if all are default
    sentAt: string               // ISO datetime
  }

  function encodeShare(payload: SharePayload): string  // returns querystring fragment value, e.g. "v=1&d=..."
  function buildShareUrl(payload: SharePayload, base?: string): string  // full URL
  function decodeShare(value: string): SharePayload    // accepts the querystring value OR a full URL
  ```

  Tests:
  - Round-trip: `decodeShare(encodeShare(p)) deep-equals p` for:
    - One child only.
    - Multiple children.
    - With custom medications added.
  - `sentAt` is preserved.
  - `temp` field on Child is **stripped** during encode (it's transient and
    privacy-bearing — never share the kid's current measurement).
  - Panic-mode-related fields (none in V1, but document the rule): not
    present in the payload.
  - Decoding garbage (`"???"`) throws a typed `ShareDecodeError`.
  - Decoding a payload with `v: 2` throws `ShareDecodeError` with
    `code: 'version'`.
  - URL length is bounded: 5 children + 0 custom meds fits in <2000 chars
    (the practical limit for many SMS clients). Add a test that asserts
    `encodeShare(largeButReasonable).length < 2000`.
  - Encoding uses URL-safe base64 (no `+`, `/`, `=`) of the compressed JSON.
    Use the browser's `CompressionStream('gzip')` if available, else fall
    back to raw JSON. Tests should run in jsdom — confirm
    `CompressionStream` availability or feature-detect.

  Avoid: any external dependency (lz-string, pako). Use Web APIs only
  (`TextEncoder`, `btoa`, `CompressionStream` if present). Keep the bundle
  small.
  </action>
  <verify>
  All tests fail with module-not-found.
  </verify>

<task type="auto">

  <files>
  src/components/design/share/encoder.ts,

  </files>
  <action>
  Implement to spec. Notes:
  - `encodeShare`: serialize to JSON → optionally gzip via
    `CompressionStream` → base64-url-safe → return as `v=1&d=<b64>`.
  - `decodeShare`: parse querystring → base64-url-decode → optionally
    gunzip via `DecompressionStream` → JSON parse → version-check →
    return typed payload.
  - `buildShareUrl(payload, base)`: defaults `base` to
    `window.location.origin + import.meta.env.BASE_URL`. Returns the full
    `https://.../?import=<encoded>` URL.
  - Strip `temp` from every child before encoding. Be explicit in code:
    `const { temp, ...safe } = child` — do NOT serialize the original
    object directly.
  - `ShareDecodeError` is a custom Error subclass with a `code` field whose
    values are: `'format' | 'version' | 'corrupt'`.

  Avoid: hand-rolling base64. Use `btoa` + URL-safe replace.
  </action>
