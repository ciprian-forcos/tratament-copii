<objective>
When the app loads with an `?import=...` parameter in the URL, intercept it,
decode the payload, and present a confirm-and-merge sheet to the user. The
user sees what's about to be imported (per-child summary) and can either
"Importă" (merge into local state) or "Anulează" (discard). After confirming,
the URL parameter is removed via `history.replaceState` so a refresh doesn't
re-trigger the prompt.

Purpose: Closes the loop on Tier 1 sharing. Without this, the receiver of a
shared link has no path to land the data.
Output: An `ImportGate` component mounted at the app root that handles the
URL → confirm → merge flow.
</objective>
