<objective>
Make the **treatment-plan** schedule rules the single source of truth and fix
the cross-drug spacing in the active dose path. Canonical rule (user-confirmed,
medical authority = the user): **Nurofen every 8h, Panadol every 8h, minimum
4h between a Nurofen dose and a Panadol dose.** The current 2h/3h/6h values are
leftover prototype aberrations.

Purpose: the deployed `buildPlan()` in `dosePlan.ts` is a naive prototype that
hardcodes a 2h alternation inline and **never reads `scheduleRules.ts`**. The
rules data is only consumed today by the legacy `ProgramTab` via
`scheduleEngine.ts`. This plan corrects the rules data AND wires the active
treatment-plan path to derive its spacing from that data, so changing the data
changes the computed plan.

Output: corrected `src/data/scheduleRules.ts`, a rules-driven `dosePlan.ts`
(no inline spacing literals), and a new `dosePlan.test.ts`.
</objective>
